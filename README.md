# Проект Mesto

Интерактивный веб-проект по размещению фотографий на странице с возможностью редактирования профиля, добавления и удаления карточек, а также постановки лайков.

## Ссылка на проект

[Посмотреть проект](https://k-tumanov.github.io/mesto-production/)

## Технологии

- HTML5
- CSS3 (BEM)
- JavaScript (ES6+)
- Vite (сборщик)
- GitHub Pages (хостинг)
- GitHub Actions (автоматический деплой)

## Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск локального сервера разработки

```bash
npm run dev
```

Сервер запустится на порту 5173 и автоматически откроет страницу в браузере.

### Сборка проекта

```bash
npm run build
```

Собранный проект появится в папке `dist`.

### Публикация на GitHub Pages

```bash
npm run deploy
```

## Настройка автоматического деплоя

Для автоматической публикации проекта на GitHub Pages необходимо:

1. Создать публичный репозиторий для размещения собранной версии проекта
2. Создать Personal Access Token с правами `repo`
3. Добавить секреты в приватный репозиторий:
   - `PUBLIC_PAGES_TOKEN` — Personal Access Token
   - `PUBLIC_PAGES_REPO` — имя публичного репозитория в формате `username/repo-name`
   - `PUBLIC_PAGES_BRANCH` (опционально) — ветка для публикации (по умолчанию `main`)

## Функциональность

- Загрузка данных пользователя и карточек с сервера
- Редактирование профиля (имя, описание)
- Обновление аватара пользователя
- Добавление новых карточек
- Удаление карточек (только автором)
- Постановка и снятие лайков
- Просмотр изображения карточки в модальном окне
- Валидация форм

## API

Проект использует API Mesto: `https://mesto.nomoreparties.co/v1/cohort_XX`

Для работы с API необходимо передать токен авторизации в заголовке запроса.
